# Adding certification and training photos

## Files to add to your repo

    _includes/gallery.html          (new)
    _includes/lightbox.html         (new)
    assets/css/gallery-append.css   (paste contents into main.css)

Then create these folders and drop your images in:

    assets/img/gallery/certifications/
    assets/img/gallery/trainings/

You can add more folders — any name works.

## Wire up the lightbox

In _layouts/default.html, add this line just before </body>,
after the existing theme <script> block:

    {% include lightbox.html %}

This goes in the layout once, not on every page.

## Add the CSS

Open assets/css/gallery-append.css, copy everything, and paste it at
the end of assets/css/main.css — before the existing @media print
block if you have one, otherwise just at the bottom. Then delete
gallery-append.css; it was only a delivery vehicle.

## Use it in cv.md

Put this line wherever you want a strip to appear:

    {% include gallery.html folder="certifications" label="Certificates" %}

For example, right after your Certifications list:

    ## Certifications

    * Datacamp Data Scientist Associate
    * ...

    {% include gallery.html folder="certifications" label="Certificates" %}

And after the conferences section:

    {% include gallery.html folder="trainings" label="Training and conferences" %}

## Naming your image files

Captions come from the filename. Use a number, then an underscore,
then hyphenated words:

    01_datacamp-data-scientist-associate.jpg   -> "datacamp data scientist associate"
    02_google-business-intelligence.jpg        -> "google business intelligence"
    03_wipo-dl101.jpg                          -> "wipo dl101"

The number controls sort order and is stripped from the caption.
Files without an underscore use the whole filename as the caption.

## Image preparation

This matters more than it sounds. Certificate scans straight from a
phone are often 4-8 MB each; ten of those will make your CV page
take several seconds to load, which hurts both visitors and your
Google ranking.

Resize to about 1200px on the long edge and save as JPG at 80%
quality. On Ubuntu:

    sudo apt install imagemagick
    cd assets/img/gallery/certifications
    mogrify -resize 1200x1200\> -quality 80 *.jpg

Check the result with: du -sh .
Aim for under 200 KB per image.

Thumbnails are generated by CSS from the same file, so you only need
one copy of each image.
