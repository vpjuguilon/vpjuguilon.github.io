## Selected Portfolio Projects

**Patent Filing Kinematics** — *Ongoing*
A research project reframing patent filing data as a dynamical system
(cumulative filings as position, filing rate as velocity, year-over-year
change as acceleration) to build phase-space diagnostics for IPC technology
classes. Built on Google Patents Public Data via BigQuery, with a Python
pipeline for data extraction and analysis. Targeting a mini-conference
presentation and submission to *World Patent Information*.
[GitHub repo link] · [Live demo / write-up link]

**THz Waveform & Spectrum Bench**
A browser-based analysis tool built for the NIP THz Team, supporting
time-domain spectroscopy & FFT analysis, power-fit curve fitting with a
custom Levenberg–Marquardt solver, and stackable FFT convolution/deconvolution
workflows. Built in React (Recharts, MathJS, PapaParse), deployed on Vercel.
[GitHub repo link] · [Live tool link]
